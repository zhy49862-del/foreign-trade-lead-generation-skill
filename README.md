# 外贸自动获客 Skill · 核心版

给外贸业务员和 AI 助手使用的海外客户开发流程。输入产品、目标国家和客户类型，用当地语言组合搜索词，从 Google 地图收集候选公司，再根据官网证据区分经销商、租赁公司和终端买家。最终输出按跟进优先级排列的 Excel 客户表，可据此起草开发信，由业务员复核后发送。

## 怎么用

1. 复制并填写 [开始前填空](开始前填空.md)，每次选一个国家。
2. 打开 [SKILL.md](SKILL.md)，按七步流程推进。[queries](queries/) 提供欧美市场的搜索词样例。
3. 按目标产品和国家调整 [scripts](scripts/) 中的关键词、号码规则和输入输出路径，再用模板清洗名单、补充业务联系方式并生成 Excel。

核心版包含流程和模板。地图抓取器与浏览器需另行配置，仓库不附客户名单。表中的 WhatsApp 链接由号码生成，注册状态需要人工确认。
