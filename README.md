# 外贸自动获客 Skill · 核心版

用你自己的产品、目标市场和理想买家，生成一张按跟进优先级排列的潜在客户表。

- **找客户**。把产品、买家类型和城市组合成当地语言的搜索词，通过 Google 地图找出候选公司，再按官网域名、电话等信息去重。
- **给客户分级**。先定义什么样的公司值得优先联系，再读官网上的业务介绍和产品信息，判断匹配程度。Excel 表保留公司、等级和判断来源，方便销售复核。

例如，做食品包装的供应商想找墨西哥的食品生产商，可以用西班牙语的买家行业词和城市名搜索，把官网明确展示目标食品生产线的企业列为优先跟进对象。仓库中的欧美机械行业脚本展示了另一套选词和分级规则。换行业时应一起调整买家类型、关键词、排除条件和等级映射。

## 从哪里开始

1. 填写 [需求表](开始前填空.md)，选定本次产品、目标地区、搜索城市和优先客户类型。
2. 按 [Skill 流程](SKILL.md) 准备搜索词。地图采集使用 [抓取器源码](tools/google-maps-scraper)，[queries](queries/) 中有当地语言搜索词示例。
3. 在 [Python 源码](scripts/) 中选用接近目标市场的模板，调整清洗、分级、语言与号码规则及文件路径，再导出 Excel。已有地图采集结果时，可以直接从清洗开始。

地图抓取器以固定版本的 Git 子模块引入。仓库有访问权限的用户可以用下面的命令同时下载 Skill 和抓取器源码，再按抓取器自带的 README 配置运行环境。

```sh
git clone --recurse-submodules https://github.com/zhy49862-del/foreign-trade-lead-generation-skill.git
```
